ReelBot is a personal place saver built with Expo and React Native, a queue-only native iOS share extension, FastAPI, a Python extraction worker, and Postgres: save a reel locally without an account, extract every named venue, resolve it through a global place cache, and organize private places into folders with notes and search; Apple sign-in is optional for cross-device sync. WhatsApp, messaging, multiplayer, and group features are permanently out of scope and must not be reintroduced. Preserve personal ownership, the native shared-container queue, offline durability, reviewable uncertainty, bounded processing, and measured ingestion costs; the isolated Debug-only interest view does not authorize any shared-library or communication capability.
