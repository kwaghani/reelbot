ReelBot is a personal reel saver built with Expo and React Native, a queue-only native iOS share extension, FastAPI, a Python extraction worker, and Postgres. Save reels locally without an account, extract every useful entry through the runtime content registry, and organize private entries into type and facet folders with notes and search. Location is an optional linked-place property backed by a global place cache; only anchored entries appear on the map. Apple sign-in is optional for cross-device sync. WhatsApp, messaging, multiplayer, and group features are permanently out of scope and must not be reintroduced. Preserve personal ownership, the native shared-container queue, offline durability, reviewable uncertainty, bounded processing, and measured ingestion costs. The isolated Debug-only interest view does not authorize any shared-library or communication capability.
